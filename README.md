# Генератор четырёхзначного кода

Веб-сервис для генерации случайных четырёхзначных кодов. Проект состоит
из backend на FastAPI и frontend на Vue.js

## Возможности

-   **Главная страница (`/`)** -- показывает случайный четырёхзначный
    код. При обновлении страницы запрашивается новый код.
-   **Защищённая страница (`/secure`)** -- доступна после регистрации и
    входа в аккаунт. На странице можно получать новые коды.
-   **Регистрация и авторизация** -- создание учётной записи и
    получение доступа к защищённой части сервиса.

## Технологии

**Backend:** Python 3.12+, FastAPI, SQLAlchemy, Alembic, PostgreSQL,
Poetry.

**Frontend:** Vue, JavaScript.

## Локальный запуск

Сначала настройте и запустите backend: инструкции находятся в
[backend/README.md](backend/README.md).

Затем запустите frontend по инструкции в
[frontend/README.md](frontend/README.md).

После запуска обеих частей приложение будет доступно по адресу
`http://localhost:5173`.

## Развёрнутая версия

Проект развёрнут на [Render](https://render.com/), база данных PostgreSQL размещена в [Neon](https://neon.tech/).

Можно открыть приложение по ссылке: https://code-generator-frontend-u36n.onrender.com

Поскольку для размещения проекта используется бесплатный тариф Render, сервер автоматически останавливается при отсутствии активности. При первом переходе по ссылке после простоя необходимо подождать около минуты, пока сервер перезапустится.
