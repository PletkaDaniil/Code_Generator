# Frontend

Frontend проекта отвечает за пользовательский интерфейс приложения и взаимодействие с backend для отображения результатов генерации кодов.


## Запуск frontend части проекта

### 1. Переход в директорию и установка зависимостей

Переходим в директорию `frontend`:

```bash
cd frontend
```

Устанавливаем зависимости проекта:
```bash
npm install
```

Для выполнения команд необходимо предварительно установить Node.js и npm.


### 2. Настройка адреса backend

Пример настройки находится в файле [frontend/.env.example](.env.example). Создайте `.env` на его основе и указываем адрес backend, например:

```env
VITE_API_URL=http://127.0.0.1:8000
```

### 3. Запуск приложения
Для запуска frontend в режиме разработки выполняем:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

"http://localhost:5173"
