# Backend

Серверная часть проекта реализована на FastAPI и отвечает за обработку запросов, генерацию четырёхзначных кодов, регистрацию и авторизацию пользователей, а также взаимодействие с базой данных PostgreSQL.

## Запуск backend части проекта

### 1. Переход в директорию и установка зависимостей

Переходим в директорию `backend`:

```bash
cd backend
```

Создаём виртуальное окружение (команда может отличаться в зависимости от системы: например, python или python3):

```bash
python -m venv venv
```

Активируем виртуальное окружение.

 - **Windows:**

```bash
venv\Scripts\activate
```

 - **Linux / macOS**:

```bash
source venv/bin/activate
```

Устанавливаем Poetry:

```bash
pip install poetry
```

Устанавливаем зависимости проекта:

```bash
poetry install
```

### 2. Настройка переменных окружения

Перед запуском необходимо создать файл .env в корне директории backend (можно использовать пример [backend/.env.example](.env.example)).

В нем указываются параметры подключения к базе данных PostgreSQL, а также адреса frontend-приложения, которым разрешено обращаться к backend через CORS (ALLOW_ORIGINS):

```bash
PG_USER=
PG_PASSWORD=
PG_HOST=
PG_PORT=
PG_DBNAME=

ALLOW_ORIGINS=[...]
```

Необходимо указать параметры уже существующей базы данных, а также адреса frontend-приложения, которым разрешено обращаться к backend. При запуске миграций Alembic автоматически создаст необходимые таблицы и обновит их структуру.

### 3. Применение миграций базы данных

Для создания и обновления таблиц необходимо выполнить:

```bash
poetry run alembic upgrade head
```

Если в дальнейшем структура базы данных изменится, новую миграцию можно создать командой:
```bash
poetry run alembic revision --autogenerate -m "migration description"
```

### 4. Запуск сервера

После установки зависимостей и настройки базы данных запускаем сервер:
```bash
poetry run uvicorn src.main:app
```

Для режима разработки можно добавить флаг --reload, который автоматически перезапускает сервер при изменении исходного кода:
```bash
poetry run uvicorn src.main:app --reload
```

После запуска сервер будет доступен по вашему адресу, например:

"http://127.0.0.1:8000"
